# ashu.

My personal portfolio. Built with plain HTML, CSS and JavaScript — no frameworks, no build step.

## What's inside

- Warm paper-toned editorial design with Fraunces type
- Live IST clock, skills marquee, numbered project rows
- Rotating "open to internships" badge
- Responsive nav with reveal-on-scroll animations
- Contact form with client-side validation

## Run it

Just open `index.html` in a browser. That's it.

Or serve it locally:

```
npx serve .
```
